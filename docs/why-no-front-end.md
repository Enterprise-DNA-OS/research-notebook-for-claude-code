# Why a research notebook without an editing screen

The base is a private research desk: record a hypothesis, retain the protocol version, append observations, locate evidence, record a human review and prepare a handover. A coding agent runs those operations through one tested CLI. Read-only HTML reports give the operator something to inspect and print.

A browser notebook provides rich text editing, inline images, mobile capture, shared access and integrated scientific tools. This base uses text records and retained files. It has no mobile app, no offline sync between devices, no drag-and-drop notebook, no chemical drawing editor and no instrument integration. Network access is not needed to operate the local database; external fonts in generated reports are optional presentation resources.

The LabArchives importer preserves its read-only archive and extracts searchable text. It does not recreate its full editing experience or regulated signatures. A lab relying on a validated workflow needs a separately validated system. Enterprise DNA can scope custom screens, access controls and integrations for a non-clinical installation through Omni by Enterprise DNA.
